# Basic agent example

This synthetic example proves the public harness composition root with:

- a deterministic mock model gateway;
- a generic `echo` tool registry;
- policy before tool execution;
- approval, audit, and telemetry ports; and
- a single-pass `Hello` response plus an explicit tool request.

It has no network, database, real tenant, clinical, financial, or Secretary
dependency. The example is intentionally not an autonomous agent loop.
