# Minimum Viable Harness

## MUST_HAVE

- neutral versioned contracts;
- injectable profile/capability/policy catalogs;
- governed single-turn runtime;
- typed stop/pause and approval resume;
- model gateway;
- unified capability registry;
- tenant/correlation identity;
- durable idempotency/effect ports;
- mandatory audit/telemetry ports;
- consumer-contract suite com dois produtos.

## SHOULD_HAVE

PostgreSQL/outbox worker adapters, prompt/profile registry corrigido, knowledge/evidence port, shadow execution, checkpoint store e OTel exporter.

## LATER

Iterative orchestrator, long-term memory, full Skill Registry/loader, MCP adapter, generic control-plane app e production shadow.

Menor v0.1 útil: contracts + runtime single-turn + policy/approval + model + capability + audit ports, com Secretary e um cliente Corp sintético. Não incluir UI, clinical catalog, journeys, provider/channel concreto ou RAG corpus no core.
