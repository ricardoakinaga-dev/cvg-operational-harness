## Lane A: external fenced outbox + renewal transaction seam

Own outbox.ts, postgres-outbox.ts, postgres.ts, tenant-scoped-postgres.ts, outbox-content-hash.ts if needed; new tests named pare217-fenced-outbox / pare217-renewal-transaction. No index.ts edits (Lead exports). Existing unbound API unchanged.

New exported supported types in outbox.ts:
- FencedOuterClaimRef {tenantId:TenantId,eventId:string,processWorkerId:string,expectedOuterAttempt:number,expectedAttemptRowId:string} (positive decimal bigint identity string, no lossy Number).
- FencedClaimedEvent {event:OutboxEventRecord,claimRef:FencedOuterClaimRef,dbClaimedAt:string}.
- FencedRenewalControl {signal:AbortSignal,assertActive:()=>void}; guards before/after every await and before COMMIT after tenant cleanup.
- FencedClaimRenewal {claimRef:FencedOuterClaimRef,dbNow:string,leaseUntil:string}.
- FencedOutboxClaimAdapter extends DurableOutboxAdapter with claimNextFenced(input:OutboxClaimInput):Promise<FencedClaimedEvent|null>; renewOutboxClaim(ref:FencedOuterClaimRef,control:FencedRenewalControl):Promise<FencedClaimRenewal>; ackClaim(input:OutboxAckInput & {claimRef:FencedOuterClaimRef,beforeFinalAck:()=>Promise<void>,signal?:AbortSignal}):Promise<OutboxEventRecord>; failClaim(input:OutboxFailInput & {claimRef:FencedOuterClaimRef}):Promise<OutboxEventRecord>.
- FencedRenewalStoppedError extends Error with signal:AbortSignal; only thrown for own guard/signal invalidation, never relabel SQL/cleanup/commit errors. Registry ignores expected stop only with exact signal identity and verified cleanup, not arbitrary rejection.

New internal helpers: renewOutboxClaimOnClient(client,ref,control?) returns FencedClaimRenewal, no BEGIN/COMMIT/checkout; runFencedRenewalTransaction(pool,tenantId,control,operation) in tenant-scoped-postgres.ts with queryRenewal helper checks before/after awaits. Exact parameters exported for package-internal consumers; public withTenantTransaction delegates same internal body unguarded. Bound helpers do DBclock after lock waits, exact attempt-row identity, no lease resurrection. A should promptly publish types and helper signatures then continue implementation.

Normative TTL=10000ms, tick2000ms. New fenced path cannot take test-only TTL. ACK preserves preparation tx -> effect outside tx -> hook outside locks -> final tx, same client retained, then cleanup. fail/ACK/takeover all recheck exact ref and DBtime. Existing unbound signatures/clock remain unchanged.
