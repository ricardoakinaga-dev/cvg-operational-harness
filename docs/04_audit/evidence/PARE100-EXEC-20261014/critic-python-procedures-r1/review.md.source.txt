Nenhuma aresta é registrada; o filtro entrega a notificação porque `parentSessionId == raiz`. Apenas `childSessionId:"s"` também permite entrega. Os dois IDs ausentes não casam; self-edge não registra aresta, mas pode ser entregue. O fan-out de `:397–415` usa esse predicado.
