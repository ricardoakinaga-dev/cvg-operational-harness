## Limites importantes para o revisor

- Não há callable de resume/cancel declarado nesses cinco módulos; o requisito de 0378 permanece aberto com oráculo UNKNOWN até contrato/fonte específicos. `session.open`, polling e cancelamento/close local não provam retomada ou cancelamento remoto.
- A referência ignora certas linhas malformadas e normaliza alguns payloads não objeto para `{}`. CVG valida de outro modo. Diferenças estão preservadas; propostas não concedem waiver de segurança nem exigem copiar fragilidades sem T3.
- `Session.run` não tem deadline próprio para receipt/idle. O procedimento propõe janela finita de observação e EOF sintético para cleanup, sem inventar timeout interno.
- O último `proc.wait()` após kill não tem timeout explícito no fonte. Não foi prometido shutdown totalmente limitado, flush durável confirmado, contenção de processo ou kill de descendentes.
- `NotificationSubscription.close` não promete limpar a fila nem acordar next já bloqueado. Proposta serial não afirma resolver a corrida de snapshot/fanout concorrente.
- Campos anotados/dataclasses/aliases não implicam validação automática; coerção e API herdada de Pydantic ficam fora da completude. `reason.kind` não foi convertido para STOP_REASONS CVG.
- Sem leitura de env/config/credenciais reais, import/execução de referência ou CVG, testes comportamentais, rede, DB, install, subagentes, comparação de runtime, commit/push ou alteração de código/docsRoot. Um script temporário local de geração foi removido; só os quatro artefatos solicitados compõem a entrega.
