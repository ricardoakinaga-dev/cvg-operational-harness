Hash documental é SHA-256 dos bytes UTF-8 após Prettier. Hash modular é SHA-256 dos bytes de JSON canônico (ensure_ascii=false, sort_keys=true, separators comma/colon) com `{module, document, parts:[{heading,text}]}`; cada text é a seção Markdown inteira, inclusive newline final. As seções comuns, próprias e compatibilidade selecionadas constam no manifesto. Digest de fonte não prova que todos os branches foram inspecionados ou executados. HEAD+source digests identificam o checkout local compartilhado; divergência posterior exige recon/revisão, não transferência automática de approval.
