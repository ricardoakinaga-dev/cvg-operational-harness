## D01 / AAA-21 boundary

The continuous worker accepts a `sweeps` handle by dependency injection and starts/stops it with the
worker lifecycle (tests 19). The real entrypoint logs `worker.sweeps_disabled`
(`reason=approval_engine_composition_pending_aaa21`) because no durable `ApprovalEngine`/`EffectJournalPort`
composition exists in the worker without AAA-21/D01. No runtime-choice composition was added.
