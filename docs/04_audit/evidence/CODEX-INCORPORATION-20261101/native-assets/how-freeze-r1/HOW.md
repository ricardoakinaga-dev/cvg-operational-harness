# Transporte de assets nativos para o contexto do runtime

Task `CODEX-INCORPORATION:NATIVE-ASSET-DELIVERY`, unidade interna T2 de build. Objetivo: o contexto compilado transportar os assets binários já produzidos no diretório `native/` de um workspace. Esta unidade não compila, escolhe, instala ou carrega um backend nativo e não altera o contrato de observação de retornos.

## Alteração prospectiva

Somente três arquivos na candidata: `scripts/build-runtime.mjs`, novo `scripts/lib/runtime-native-assets.mjs` e novo `tests/runtime-native-assets.test.js`. Helper interno sem export em pacote de produto; chamado pelo builder com root/context/workspaces já definidos pelo próprio builder. Sem mudança de RUNTIME_WORKSPACES, flags/compiler, manifest/lock, containers, package exports, runtime-context.json ou comportamento de seleção de perfis.

Depois da compilação e antes da escrita do manifesto final do contexto, incluir o `native/` opcional de cada workspace no mesmo caminho relativo do contexto. O helper primeiro inventaria todas as árvores selecionadas, depois copia os arquivos. Diretório ausente é caso normal; se existe, exige diretório regular e filhos regulares/diretórios, sem symlinks ou arquivos especiais. Assets aceitos: `.node` e `.json`; qualquer fonte/script/outro tipo nesse diretório faz o build falhar, para preservar sourceIncluded:false. Arquivos e layout relativos permanecem byteiguais, com os bits de permissão normais preservados; não interpretar ou executar conteúdo. Não seguir symlink, não copiar source/arquivos fora das árvores, não inferir ABI, plataforma, assinatura ou autenticidade pelo sufixo. Copiar assets não é admissão para o loader. Caminhos e erros são relativos aos workspaces conhecidos, sem ler configuração arbitrária.

O helper não remove/limpa diretórios e não gera código; a limpeza do contexto continua no builder existente. Em falha, o builder retorna nãozero e não escreve um novo runtime-context.json de sucesso. Esta unidade não adiciona execução de compiler nativo nem mecanismo novo de loading. Ausência de assets conserva a composição legada e o pacote raiz importa normalmente.

## Critérios e contraprovas

| ID  | Aceite                                                                                                                                        | Controle que reprova                                                                                                           |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| A01 | Builder público transporta um asset opaco e metadataJSON de package-root-native para o contexto real, com bytes/layout/modos conferidos.      | Baseline compila, mas asset não chega ao contexto; copiar somente dist não pode passar.                                        |
| A02 | Pacotes sem native mantêm os mesmos manifests/dist e a lista20workspaces.                                                                     | Introduzir novo workspace, campo de manifesto ou flag/compiler não pertence a esta task.                                       |
| A03 | Árvore regular aninhada é copiada; validação de todos os assets antecede sua cópia.                                                           | Symlink relativo/absoluto, raiz falsa ou arquivo especial fazem falhar; nenhum alvo externo é copiado.                         |
| A04 | Diretório native não vira fonte/script embarcado.                                                                                             | `.ts`, `.js`, `.cc` ou outro arquivo não selecionado fazem falhar sem novo manifesto de sucesso.                               |
| A05 | Contexto novo com asset atualizado contém o novo hash; não recebe lixo de execução anterior.                                                  | Segundo build não pode reutilizar o asset/dist antigos para produzir verde.                                                    |
