## Alteração prospectiva

Somente três arquivos na candidata: `scripts/build-runtime.mjs`, novo `scripts/lib/runtime-native-assets.mjs` e novo `tests/runtime-native-assets.test.js`. Helper interno sem export em pacote de produto; chamado pelo builder com root/context/workspaces já definidos pelo próprio builder. Sem mudança de RUNTIME_WORKSPACES, flags/compiler, manifest/lock, containers, package exports, runtime-context.json ou comportamento de seleção de perfis.

Depois da compilação e antes da escrita do manifesto final do contexto, incluir o `native/runtime/` opcional de cada workspace no mesmo caminho relativo do contexto. O helper primeiro inventaria todas as árvores selecionadas, depois copia os arquivos. Raiz native ausente ou native regular sem runtime é caso normal, inclusive native contendo fontesClegítimos; não copiar nem modificar os irmãos de runtime. native e o runtime selecionado, quando presentes, exigem diretórios regulares sem symlinks; dentro de runtime só filhos regulares/diretórios, sem links ou arquivos especiais. Assets aceitos: `.node` e `.json`; qualquer fonte/script/outro tipo **dentro do runtime selecionado** faz o build falhar, para preservar sourceIncluded:false. Arquivos e layout relativos permanecem byteiguais, com os bits de permissão normais preservados; não interpretar ou executar conteúdo. Não seguir symlink, não copiar source/arquivos fora das árvores, não inferir ABI, plataforma, assinatura ou autenticidade pelo sufixo. Copiar assets não é admissão para o loader. Caminhos e erros são relativos aos workspaces conhecidos, sem ler configuração arbitrária.

O helper não remove/limpa diretórios e não gera código; a limpeza do contexto continua no builder existente. Em falha, o builder retorna nãozero e não escreve um novo runtime-context.json de sucesso. Esta unidade não adiciona execução de compiler nativo nem mecanismo novo de loading. Ausência de assets conserva a composição legada e o pacote raiz importa normalmente.
