# Independência das revisões

O crítico do produto na rodada anterior iniciou com identidade/contexto novos, mas leu incidentalmente ledgers e coordenação para cumprir regras gerais; sua independência I1 foi parcial. Os reprodutores HTTP de identidade e de ciclo de vida, os sentinels e a comparação direta das asserções são controles novos verificáveis por execução, sem depender da narrativa histórica. O aceite geral não é inferido deles.

O novo crítico R2-P4 receberá somente regras aplicáveis seladas, SPEC aprovada, 14 critérios, fontes congeladas, artefato público e inputs originais 37. A instrução explícita do usuário exige nenhum acesso a ledgers/coordenação/pareceres anteriores. Essa exceção de leitura vale apenas para esse crítico.
